# Roadmap

## Current Status

Facee currently has a polished customer storefront baseline:

- localized storefront shell
- category/product catalog
- product detail page
- customer auth
- cart and checkout
- sandbox payment flow
- customer account/profile management
- customer order history
- NestJS storefront API plus customer/account/order endpoints

## Implemented Commerce Scope

- cart quantity management and stock-aware refresh
- checkout with saved address selection
- payment method selection before order placement
- sandbox QR payment and sandbox card confirmation
- saved demo cards in the customer profile
- order success page and order detail page
- compare-at pricing and flash sale presentation
- predictive product search in the storefront topbar

### Authentication

- account recovery
- email verification
- broader security hardening

### Admin

- admin dashboard shell expansion
- product CRUD
- category management
- flash sale and merchandising controls
- publish/unpublish workflow
- payment review tools
- inventory operations

### Content and Media

- homepage/editorial sections
- category cover assets
- richer merchandising content controls

### Deployment

- Vercel deployment guide refinement
- Docker setup
- production environment notes

## Notes

This roadmap intentionally keeps planned work visible so the repo documents both
what exists now and what is still ahead.
