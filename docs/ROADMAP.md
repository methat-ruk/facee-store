# Roadmap

## Current Status

Facee currently has a polished public storefront baseline:

- localized storefront shell
- category/product catalog
- product detail page
- login/register UI
- NestJS storefront API

## Next Priorities

### Commerce Flow

- cart page
- quantity editing outside the PDP
- checkout-ready order summary

### Authentication

- real login/register API integration
- protected account flow
- session or token strategy

### Admin

- admin auth
- admin dashboard shell
- product CRUD
- category management
- publish/unpublish workflow

### Content and Media

- richer product galleries
- homepage/editorial sections
- category cover assets

### Deployment

- Vercel deployment guide refinement
- Docker setup
- production environment notes

## Notes

This roadmap intentionally keeps planned work visible so the repo documents both
what exists now and what is still ahead.
